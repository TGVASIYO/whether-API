## 📌 About

A simple desktop weather application built using **Python** and **Tkinter**. It fetches real-time weather data using the **OpenWeather API** and displays temperature and weather conditions in a clean, minimal GUI.

---

## ✨ Features

| | Feature |
|---|---|
| 🔍 | Search weather by city name |
| 🌡️ | Displays temperature in Celsius |
| ☁️ | Shows current weather condition |
| ⚠️ | Handles invalid city input gracefully |
| 🖱️ | Simple and user-friendly interface |

## 🚀 Installation

```bash
git clone https://github.com/your-username/weather-app.git
cd weather-app
pip install requests
```

Then run:

```bash
python weather.py
```

> 💡 **Note:** You'll need a free API key from [OpenWeatherMap](https://openweathermap.org/api) — add it to the script before running.
